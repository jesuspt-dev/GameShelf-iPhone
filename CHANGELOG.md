# Changelog

## 1.1 — Console Artwork Rework

- Corregida la cuadrícula principal que podía desbordar horizontalmente por el tamaño intrínseco de las imágenes remotas.
- Tarjetas de consola con dos columnas de anchura uniforme.
- Nuevo pipeline de recorte local de hardware con Apple Vision.
- PNG transparente en caché para cada consola.
- Imágenes con `scaledToFit`, centradas, proporcionadas y con padding constante.
- Hero de la vista de consola rediseñado para usar el dispositivo aislado y no una foto a sangre.
- PC utiliza una fuente de hardware más apropiada (`Computer case`).
- Migración no destructiva de fuentes antiguas; el esquema SwiftData no cambia.
- Opción en Ajustes para regenerar la caché de imágenes.
- Versión de app subida a 1.1 (build 2).
